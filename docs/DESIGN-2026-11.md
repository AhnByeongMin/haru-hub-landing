## 1. 방향 결정

**결정: "밤의 운영 일지" — 시안 C(밤 관제 지도)의 색과 지도를 뼈대로, 시안 B(작업 일지)의 '기록' 문법을 글 구조로 섞는다.**

이 사람의 주제는 "불필요한 과정을 지우고, 그 결과를 혼자 끝까지 운영한다"입니다. 그걸 가장 정직하게 보여 주는 화면은 꾸민 포스터가 아니라 **지금 실제로 불이 켜져 있는 기계 지도**와 **날짜가 찍힌 기록**입니다. 그래서 첫 화면 오른쪽(폰에서는 바로 아래)에 집 안 서버를 그린 작은 등각 지도를 두고, 바깥 감시기의 실데이터가 도착하는 순간 서비스 등불이 차례로 켜집니다. 이것이 페이지의 유일한 연출입니다. 나머지는 모두 B의 문법(왼쪽 정렬, 고정폭 글꼴의 날짜·시각 표시, 기록 항목처럼 끊어 쓴 문단)으로 차분하게 읽힙니다. 색은 다크 기반(사용자 선호)이지만 '거의 검정 + 형광 포인트 하나'가 아니라 **청록빛 밤(먹청) 바탕 + 두 가지 뜻이 다른 색** — 청자색(구조·링크)과 등불색(살아 있음·지금) — 으로, 색마다 의미가 정해져 있어 장식이 아니라 정보가 됩니다. 보여 줄 사람(채용 담당·고객·동료 개발자)이 폰으로 열었을 때 "말만이 아니라 지금 돌아가고 있다"를 3초 안에 보게 하는 것이 목표입니다.

**버린 것과 이유**

### 4. 원칙
- 섹션 머리: `원칙`
- 제목: 불필요한 동작을 지우는 것이 **가장 큰 UX 개선**이다.
- 부제: 스타트업에서 사용자 이탈을 지켜보며 생긴 기준입니다.
- 세 칸(영문 이름은 작은 고정폭 머리, 한글이 본문):
  - `Click Once` **한 번이면 끝나게** — 복잡한 분석도 버튼 하나로.
  - `Remove, not Add` **더하지 말고 지우기** — 기능을 늘리기보다 불필요한 단계를 없앱니다.
  - `Time Back to Human` **사람은 판단만** — 반복은 시스템이, 사람은 판단에 집중합니다.
- 맺음 한 줄: 이 페이지도 같은 원칙입니다. 핵심만 보이고, 필요하면 펼쳐서.

### 4.2 글꼴

- **Pretendard Variable** — 한글·영문 본문과 제목 전부. 상태판과 같은 얼굴이라 사용자 생태계가 하나로 보입니다. **자체 호스팅**: npm `pretendard@1.3.9` 의 `dist/web/variable/woff2-dynamic-subset/` 와 `pretendardvariable-dynamic-subset.css` 를 `assets/fonts/` 에 복사(글자 범위별로 쪼개진 파일이라 페이지에 쓰인 글자 묶음만 받음). `font-display: swap`.
- **IBM Plex Mono** 400·500 — 날짜 머리, 섹션 머리, 칩, 숫자 단위, 지도 이름표에만. Google Fonts, `&display=swap&text=` 는 쓰지 않고 latin 부분만(한글은 쓰지 않음 — 고정폭 자리에 한글이 오면 Pretendard로 떨어지게 글꼴 순서 지정).
- 대체 순서: `"Pretendard Variable", Pretendard, -apple-system, BlinkMacSystemFont, "Apple SD Gothic Neo", "Noto Sans KR", system-ui, sans-serif` — 아이폰에서 글꼴이 늦어도 비슷한 Apple SD Gothic Neo로 먼저 보입니다.
- 지금 쓰는 Fraunces·Inter·JetBrains Mono·Noto Sans KR 링크는 모두 삭제.

### 4.3 간격 · 격자

- 간격 단위: 4 · 8 · 12 · 16 · 24 · 32 · 48 · 72 · 112 (px). 그 밖의 값 금지.
- 섹션 위아래: 폰 72 / 데스크톱 112. 섹션 머리 → 제목 12, 제목 → 부제 12, 부제 → 내용 32.
- 바깥 여백: `padding-inline: max(16px, env(safe-area-inset-left/right))` (폰 16px, 1024 이상 32px). 내용 최대 폭 1120px, 글 덩어리 최대 680px.
- 격자: 폰 1단 / 640~1023px 2단(간격 16) / 1024px 이상 12단(간격 24). 첫 화면 데스크톱 = 글 7단 + 지도 5단. 서비스 카드 = 글 7 + 기기 틀 5, 짝수 번째는 좌우 반전하지 않음(시선이 왼쪽에서 시작하게 일관).
- **왼쪽 정렬이 기본.** 가운데 정렬은 숫자 칸 안의 숫자뿐.

### 4.4 부품

- **상단 막대**: `position: sticky; top: 0`, 높이 52px + `padding-top: env(safe-area-inset-top)`. 바탕 `rgba(12,20,22,.88)` + `-webkit-backdrop-filter: blur(12px)`(앞에 `-webkit-` 필수). 아래 `--line` 1px는 스크롤 0일 때 숨김. 링크 13.5px `--ink-2`, 현재 섹션은 `--ink` + 아래 2px 청자 선(IntersectionObserver로 표시, `aria-current="true"`). `연락` 은 등불 테두리 버튼(바탕은 비움, 글자 `--lamp`). 누르는 영역 최소 44×44.
- **증거 칸**(첫 화면): `--lamp-wash` 바탕, 반경 12, 패딩 16. 위 `meta` 이름(`--ink-3`), 아래 `stat` 숫자(`--ink`), 화살표 `→` 는 `--lamp`.
- **실시간 띠**: 5절. 높이 44px 고정, `--surface` 바탕, 반경 999, 왼쪽 등불 점 10px.
- **카드**: `--surface` 바탕, 1px `--line-strong` 테두리, 반경 16, 패딩 폰 20 / 데스크톱 28. 그림자 없음. 카드 머리는 `meta` (`01 · 핵심 프로젝트`).
- **칩**: 높이 28, 패딩 0 10, 반경 999, `--surface-2` 바탕, `meta` 글자 `--ink-2`. 마스킹 칩은 `--lamp-wash` 바탕 + `--lamp` 글자. 화면 고르기 칩은 `<button aria-pressed>`, 선택 = `--cel` 바탕 + `--bg` 글자.
- **표**(성과 ①): 진짜 `<table>` 유지(읽기 프로그램용). 폰(<560px)은 4열 대신 3열: `업무` / `기존 → 지금`(한 칸에 "수시간 → **약 2분**") / `줄어든 정도`. 줄어든 정도 칸 아래 3px 막대(`--lamp`, 폭 = %, `aria-hidden`). 머리 줄 `--surface-2`, 줄 사이 `--line`. 숫자 `tabular-nums`.
- **펼침**(`<details>`): 요약 줄 48px 높이, 오른쪽 `+`/`−` 글자(그림 아님), `summary::-webkit-details-marker { display:none }` + `list-style:none`. 안쪽 `--surface-2`, 소제목은 `meta` 청자색.

### 4.5 움직임 (연출은 하나)

**유일한 연출 — "불 켜기"**: 지도가 화면에 30% 이상 들어오고 + 실시간 데이터가 도착하면(둘 다 만족한 순간 한 번):
1. 바깥(Cloudflare) → 대문 A·B 연결선이 0.6초 동안 그려짐(`stroke-dashoffset`).
2. 서비스 등불이 왼쪽부터 70ms 간격으로 켜짐(각 220ms, `opacity`+`transform: scale(.6→1)`).
3. 실시간 띠의 숫자가 같은 순간 들어감(숫자 굴리기 없음 — 바로 표시).
전체 1.4초 안에 끝나고 반복하지 않습니다. 이후 새로 고침(60초)에서 상태가 바뀐 등불만 색이 0.3초에 걸쳐 바뀝니다.

그 밖의 움직임: 링크·버튼 색 변화 120ms, 펼침은 움직임 없이 즉시. 스크롤 등장 효과·시차 효과·커서 효과 없음. `transform`/`opacity`만 움직임(레이아웃 바뀌는 속성 금지).

### 4.6 다크/라이트 정책

- **다크 고정.** `<meta name="color-scheme" content="dark">`, `:root { color-scheme: dark }`, `<meta name="theme-color" content="#0c1416">`. 시스템이 라이트여도 같은 화면.

**출처**: `GET https://status.haru-hub.com/api/status` — Cloudflare Worker(`infra/edge-monitor`)가 5분마다(`*/5 * * * *`) 공개 주소를 바깥에서 확인한 결과.

의미(코드 확인): `since` = **지금 상태가 시작된 시각**(정상→문제, 문제→정상으로 바뀔 때만 갱신, 처음 본 날이면 감시 시작 시각). `up` 은 한 번만 실패해도 `false`(알림은 여러 번 실패 뒤).

## 7. 접근성 · 성능 예산

**접근성**
- 글자 대비 4.5 이상 전부(4.1 표, axe `color-contrast` 0건).
- 제목 순서 `h1`(첫 화면 1개) → 섹션 `h2` → 카드 `h3`. 섹션은 `<section aria-labelledby>`.
- 상단 막대 첫 항목에 `본문 바로가기` 건너뛰기 링크(포커스 때만 보임).
- 모든 영상: `aria-label`(무엇을 보여 주는지 한 문장), 옆에 같은 내용 캡션 글. 정지/재생 버튼(44×44, `aria-pressed`) — 움직이는 것이 5초 넘으면 멈출 수단 필요(WCAG 2.2.2).
- 지도 SVG: `role="img"` + `<title>`/`<desc>`; 등불 상태는 띠 글자로도 전부 읽힘(색만으로 전달 금지 — 띠·목록에 '응답 중/응답 없음' 글자).
- 칩 전환: `<button aria-pressed>`, 바뀐 그림의 `alt` 갱신.
- 포커스: `:focus-visible { outline: 2px solid var(--focus); outline-offset: 3px }`, 절대 없애지 않음.
- 확대 200%·글자 크게(iOS 동적 글자는 웹에 직접 안 먹으므로 `rem` 기반으로 사파리 '글자 크기' 설정에 따라가게).
- `lang="ko"`, 영문 기술 이름은 그대로(발음 혼동 없음).

**성능 예산** (아이폰 15, 빠른 4G 흉내 기준)

| 항목 | 목표 |
|---|---|
| LCP(첫 화면 제목 글자) | ≤ 1.8초 |
| CLS | ≤ 0.02 |
| 첫 화면까지 받는 총량(영상 제외) | ≤ 450KB (HTML ≤ 22KB 압축, CSS ≤ 12KB 압축, JS ≤ 4KB 압축, 글꼴 ≤ 300KB, 지도 SVG 인라인 ≤ 12KB, 그림 0) |
| 페이지 끝까지 내리며 받는 총량(영상 1회씩 재생) | ≤ 16MB |
| 막는 외부 요청 | 0 (Plex Mono 링크는 `media="print" onload` 방식 없이 그냥 `display=swap` 스타일시트 — 하나뿐이라 허용, 대신 `preconnect`) |
| 동시에 재생되는 영상 | 최대 1개 |

**영상 불러오기 방식**
- 모든 `<video>`: `muted playsinline loop preload="none"`, `width`/`height` 속성 + CSS `aspect-ratio`, `poster`. **`autoplay` 속성 없음**, `src` 도 처음엔 없음(`data-src`).
- IntersectionObserver(`rootMargin: 300px`): 가까워지면 `<source src type="video/mp4">` 붙이고 `load()`. 50% 이상 보이면 `play()`, 벗어나면 `pause()`. 다른 영상이 재생 중이면 그것을 멈춤(동시 1개).
- `play()` 가 거절되면(아이폰 저전력 모드·데이터 절약) 포스터 위 재생 버튼을 보여 주고 사용자가 누를 때 재생 — 조용히 멈춰 있는 화면 금지.
- `prefers-reduced-motion: reduce` 이면 자동 재생 안 함, 재생 버튼만.
- `navigator.connection.saveData` 가 참이면 자동 재생 안 함(지원 브라우저만, 사파리는 무시됨).
- 펼침 안에 있는 그림·영상은 펼칠 때 불러옴.
- 그림: `<img loading="lazy" decoding="async" width height>`, WebP. 첫 화면 그림 없음.
