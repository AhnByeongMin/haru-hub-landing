Philosophy
02 Philosophy

불필요한 동작을 제거하는 것이
가장 큰 UX 개선이다.

— 스타트업에서 사용자 이탈을 목격하며 형성된 철학
i.

Click Once

복잡한 분석도 단일 버튼 한 번으로.

ii.

Remove, not Add

기능을 더하는 대신 불필요한 것을 제거.

iii.

Time Back to Human

반복은 시스템이, 사람은 판단에 집중.

— 이 소개 페이지도 같은 원칙입니다. 핵심만 보이고, 필요하면 펼쳐서.

상담 CRM 2.0 — 운영 시스템을 다시 짓다

직접 만들어 운영하던 상담 CRM(1.x)을 여러 사람이 동시에 써도 데이터가 틀어지지 않는 구조로 처음부터 다시 설계하고, 운영을 멈추지 않은 채 옮긴 뒤 1.x를 종료했습니다. 데이터·동작은 그대로, 구조·화면은 새로.

⚠️ 데모 환경 — 실제 2.0 코드를 빈 DB로 띄우고 가상 인물·가상 제품 데이터만 넣어 촬영. 회사명은 가림.

  • 녹취 편집 · 파일 변환 · 공동 시트
  • 사용자 · 권한 · 알림 설정

Architecture

  • Proxmox 전용 LXC — 앱 · DB 분리
  • 주 · 대기 DB 스트리밍 복제 + 매일 백업
  • 행 단위 저장 · 낙관적 잠금 (통째 덮어쓰기 제거)
  • 배경 작업은 한 곳에서만 (Redis 잠금)
  • 새 컨테이너가 정상일 때만 교체하는 무중단 배포
Migration

기능을 옮길 때마다 같은 입력 → 1.x와 같은 결과인지 자동 대조(일부러 틀린 코드를 넣어 대조가 잡아내는지까지 확인). 1.x와 2.0을 실시간으로 잇는 다리를 두고 단계적으로 전환.

Verified
